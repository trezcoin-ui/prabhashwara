# prabhashwara

Prabhashwara — Yoga Practice Tracker

A mobile-first Progressive Web App for tracking daily yoga practice with a community of practitioners.

## Features

- 🧘 Track daily yoga activities (Priming, Surya Namaskaraya, Pranayama, Meditation)
- 💾 Auto-save functionality - no manual saving needed
- 📱 PWA support - install as a standalone mobile app
- 🎨 Beautiful glass morphism design with dark theme
- 📊 Daily scoring system
- 🔄 Offline support with service worker
- ⚡ Built with Next.js 16, React, TypeScript, Tailwind CSS v4

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) to see the app.

## Tech Stack

- **Framework**: Next.js 16.4 with App Router & Turbopack
- **Styling**: Tailwind CSS v4
- **Animation**: Motion (Framer Motion)
- **Fonts**: Geist Sans, Instrument Serif
- **Deployment**: Vercel
- **Database**: Supabase (coming soon)

## Deployment

Deploy to Vercel with one click or push to main branch for automatic deployment.
